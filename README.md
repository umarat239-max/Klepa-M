# Klepa Up — Telegram-бот + Mini App (версия 4)

Ваше приложение + сервер, бот, база, банк, QR, чаты, канал, рынок игроков, настройки и админ-панель. Все файлы лежат в корне, без папок.

## Обновление (данные не теряются)
1. На GitHub загрузите все файлы с заменой (Add file → Upload files).
2. Render пересоберёт сервис сам. База остаётся прежней: игроки, балансы, промокоды, отзывы, роли и переводы сохраняются.
3. Прогресс игроков не меняется: новые функции добавлены поверх. Если у игрока прогресс не подтянулся из облака, приложение восстановит звёзды и подарки из копии на сервере.

## Переход на нового бота
1. Render → Environment: новые `BOT_TOKEN` и `OPENROUTER_KEY`, `PUBLIC_URL` обязательно с `https://`, `DATABASE_URL` не менять.
2. @BotFather → новый бот → Configure Mini App / Main App → укажите `PUBLIC_URL`.
3. Добавьте бота администратором в канал @KlepaUp, иначе подписки приглашённых проверить нельзя. Проверка в админ-панели: Обзор → «Подписка на канал».
4. Откройте бота и нажмите /start. Токены и ключи вписывайте только в Render, не в код и не в чат.

## Важно знать
- Баланс и подарки хранятся в приложении игрока, сервер получает копию каждые 15 секунд. Переводы и рынок проверяются по последнему балансу, который передаёт приложение.
- Файлы чата и канала хранятся в базе Postgres. Бесплатная база Render живёт 30 дней и вмещает около 1 ГБ: для постоянной работы возьмите платный план или внешний Postgres (Neon, Supabase).
- Без `DATABASE_URL` данные пишутся в `data.json` и папку `media` (для теста; на Render пропадут при перезапуске).
- Локальный запуск: `npm install`, затем `BOT_TOKEN=... PUBLIC_URL=... node server.js`.
